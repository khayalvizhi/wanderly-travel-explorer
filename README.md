# 🌍 Wanderly – Travel Explorer

### Explore Beyond Boundaries

Wanderly is a modern, responsive travel exploration website designed to help users discover beautiful destinations, explore travel packages, and estimate their travel expenses. It provides an interactive and visually appealing experience for users who love travelling and exploring new places.

## ✨ Features

- **Beautiful Landing Page:** Attractive hero section with travel background images.
- **Destination Explorer:** Browse popular destinations around the world.
- **Search & Filter:** Search destinations and filter them based on categories and budget.
- **Favourite Destinations:** Save favourite destinations using browser LocalStorage.
- **Travel Packages:** Explore different travel packages with descriptions and prices.
- **Budget Calculator:** Calculate estimated travel expenses based on destination style, number of travellers, and travel duration.
- **Responsive Design:** Optimized for desktop, tablet, and mobile devices.
- **Interactive Navigation:** Smooth navigation with a mobile-friendly hamburger menu.

## ⚙️ Installation and Setup

Follow these steps to run the project locally:

### 1. Clone the Repository

```bash
git clone YOUR_GITHUB_REPOSITORY_URL
```

### 2. Navigate to the Project Folder

```bash
cd wanderly
```

### 3. Run the Website

Open the `index.html` file in your preferred web browser.

No additional dependencies or installations are required.

## 🚀 Deployment

This website can be deployed using **Netlify**.

### Deployment Steps

1. Visit [Netlify](https://www.netlify.com/).
2. Log in to your account.
3. Upload the project folder using Netlify Drop.
4. Wait for the deployment to complete.
5. Get your live website URL.
